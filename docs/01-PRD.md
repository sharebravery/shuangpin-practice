# 双拼练习产品需求文档

版本：v1.1  
项目名称：双拼练习（Shuangpin Practice）  
产品形态：单主页面响应式 Web 工具  
产品作者：云北  
核心目标：提供一个打开即可使用、没有学习和设置负担的现代双拼练习工具，并成为云北内容体系中的长期流量入口。

## 1. 产品背景

现有双拼练习项目主要存在三类问题：

1. 部分项目功能完整，但技术实现和视觉风格较旧。
2. 部分现代项目加入账号、云同步、后台和复杂统计，超出了简单练习工具的必要范围。
3. 一些产品进入后需要先理解大量设置，无法直接开始练习。

本产品不建设完整的双拼教学平台，也不要求用户注册或完成新手流程。

产品的核心承诺是：

> 打开页面，选择自己的双拼方案，马上开始练习。

## 2. 产品目标

### 2.1 用户目标

用户进入网站后能够：

- 不注册、不登录，直接开始练习。
- 选择自己使用的双拼方案。
- 练习键位、单字和常用词组。
- 在输入错误时立即看到正确编码。
- 查看当前方案的双拼键位图。
- 查看正确率、进度和连续正确数量。
- 刷新或再次访问后保留自己的常用设置。

### 2.2 运营目标

产品用于：

- 承接“双拼练习”“小鹤双拼练习”“微软双拼键位图”等搜索流量。
- 为云北的双拼相关文章提供配套工具。
- 通过 GitHub、少数派、公众号、掘金和社交平台传播。
- 展示云北作为产品开发者和长期双拼用户的个人身份。
- 验证“内容 + 实用工具”的引流模式。

### 2.3 第一版不解决的问题

第一版不实现：

- 用户注册和登录。
- 云端同步。
- 数据库。
- 排行榜。
- 社区。
- 好友功能。
- 积分和成就系统。
- 完整课程。
- AI 教练。
- 会员和支付。
- 后台管理。
- 小程序和原生应用。
- 用户自定义文章练习。
- 独立设置页面。

## 3. 目标用户

### 3.1 双拼新用户

已经听说双拼，希望尝试，但还没有记住全部键位。

需要：

- 打开即可尝试。
- 输入错误后看到明确解释。
- 随时查看键位图。
- 不必先阅读长篇教程。

### 3.2 正在学习双拼的用户

已经选择双拼方案，但输入时仍然需要回忆键位。

需要：

- 高频单字和词组练习。
- 错题适度重复。
- 正确率和练习进度。
- 保留上次使用的方案。

### 3.3 已经使用双拼的用户

希望偶尔复习键位、测试熟练程度，或者向朋友推荐双拼。

需要：

- 界面干净。
- 操作直接。
- 支持主流方案。
- 可以复制简单的练习结果。

## 4. 产品原则

### 4.1 单主页面

所有核心操作都在首页完成：

- 选择方案。
- 选择模式。
- 输入答案。
- 查看键位图。
- 修改设置。
- 查看结果。
- 了解产品和作者。

第一版不建立 `/settings`、`/learn`、`/dashboard` 等独立页面。

### 4.2 打开即练

首次进入页面：

- 不显示欢迎弹窗。
- 不显示强制教程。
- 不要求注册。
- 不要求先完成配置。
- 输入框自动获得焦点。
- 页面直接显示第一道题。

### 4.3 合理默认值

默认设置为：

- 双拼方案：小鹤双拼。
- 练习模式：单字练习。
- 每组题数：20 题。
- 显示拼音：开启。
- 显示键位图：开启。
- 答对自动下一题：开启。
- 错题优先：开启。
- 音效：关闭。
- 主题：跟随系统。

### 4.4 高频选项直接展示

主页面顶部直接显示：

- 双拼方案。
- 练习模式。
- 键位图显示开关。
- 更多设置。
- 主题切换。

用户不打开更多设置，也可以正常完成全部核心练习。

### 4.5 低频设置按需展开

没有独立设置页。

桌面端点击设置按钮后显示小型 Popover。

移动端点击设置按钮后，从底部打开 Drawer。

低频设置包括：

- 是否显示拼音。
- 是否优先出现错题。
- 每组题数。
- 是否自动进入下一题。
- 音效。
- 清空本地记录。

### 4.6 组件优先

只要 shadcn/ui 已提供对应组件，就必须优先使用，不允许在业务代码中重新实现。

例如：

- 按钮使用 Button。
- 选择框使用 Select。
- 开关使用 Switch。
- 设置浮层使用 Popover 或 Drawer。
- 结果弹窗使用 Dialog。
- 清空确认使用 Alert Dialog。
- 提示使用 Tooltip。
- 进度使用 Progress。
- 页面说明使用 Accordion。
- 消息反馈使用 Sonner。

只有双拼键位图、题目展示和答案反馈等领域专用界面可以自行实现。

## 5. 页面结构

页面从上到下分为六个区域。

### 5.1 顶部栏

包含：

- 产品名称。
- 云北署名或个人入口。
- 主题切换。
- GitHub 项目入口。

顶部栏保持轻量，不占用过多首屏空间。

### 5.2 练习工具栏

包含：

- 双拼方案 Select。
- 练习模式 Select。
- 键位图显示按钮。
- 更多设置按钮。

桌面和移动端均保留相同的核心选项，不为不同设备设计两套完全不同的操作逻辑。

### 5.3 主练习区

主练习区是页面最突出的部分。

单字模式示例：

```text
窗

chuāng

请输入双拼编码
```

用户输入错误后显示：

```text
正确编码：id

ch → i
uang → d
```

主练习区包含：

- 当前题目。
- 拼音。
- 输入框。
- 正确或错误状态。
- 错误后的编码拆解。
- 暂停状态。

### 5.4 练习状态

只展示三个主要数据：

- 正确率。
- 当前进度。
- 连续正确。

第一版不展示复杂图表，也不使用“每分钟汉字数”，因为用户输入的是双拼编码，并非直接通过输入法录入汉字。

### 5.5 双拼键位图

键位图位于练习区下方，可以隐藏。

要求：

- 根据当前方案显示声母和韵母。
- 输入过程中高亮已经按下的键。
- 输入错误时高亮正确键位。
- 切换方案后立即更新。
- 移动端允许横向滚动。
- 浅色和深色主题均清晰可读。

### 5.6 页面说明与作者入口

练习功能下方使用 Accordion 放置：

- 什么是双拼。
- 支持哪些方案。
- 使用方法和快捷键。
- 常见问题。
- 项目说明和开源信息。
- 云北的双拼使用文章。
- 云北的个人主页和社交入口。

说明内容默认折叠，不占用练习首屏。

## 6. 双拼方案

第一版支持：

- 小鹤双拼。
- 微软双拼。
- 自然码双拼。
- 搜狗双拼。

方案必须使用统一数据结构。

第一版不提供自定义方案编辑器。

后续可以根据用户反馈增加：

- 智能 ABC。
- 拼音加加。
- 紫光双拼。
- 自定义方案导入。

## 7. 练习模式

### 7.1 键位练习

显示一个声母或韵母，用户输入对应键位。

示例：

```text
uang → ?
```

适合尚未完全记住键位的用户。

### 7.2 单字练习

显示一个常用汉字及明确拼音，用户输入对应的两个双拼按键。

### 7.3 词组练习

显示常用词组，用户按顺序输入每个汉字对应的双拼编码。

词组中的每个汉字都必须预先配置明确读音，不在运行时猜测多音字。

## 8. 输入规则

- 输入框只接受英文字母和当前方案允许的符号。
- 默认不区分大小写。
- 关闭自动更正、自动首字母大写和拼写检查。
- 达到答案长度后自动判断。
- 回答正确时自动进入下一题。
- 回答错误时停止并显示正确答案。
- 错误后再次输入或按 Enter 进入下一题。
- Esc 清空当前输入。
- Space 暂停或继续。
- 点击练习区域后重新聚焦输入框。
- 移动端尽量调用系统英文键盘。

## 9. 错题机制

第一版使用简单错题机制，不实现完整间隔重复算法。

规则：

- 输入错误后记录该题。
- 错题在后续 3 至 8 道题之间重新出现。
- 同一道错题不会连续重复。
- 错误次数越多，重新出现概率越高。
- 用户可以在结果弹窗中选择“练习本组错题”。

## 10. 练习结果

默认完成 20 题后显示 Dialog。

内容包括：

- 完成题数。
- 正确率。
- 最长连续正确。
- 本组错题数量。

操作包括：

- 再练一组。
- 练习错题。
- 复制成绩文本。
- 关闭结果继续自由练习。

第一版不生成图片成绩卡。

## 11. 本地保存

使用浏览器本地存储保存：

- 上次使用的方案。
- 上次使用的模式。
- 显示设置。
- 累计完成题数。
- 累计正确数。
- 错题和错误次数。

不保存：

- 当前输入。
- 当前题目。
- 完整按键过程。
- 用户身份信息。
- 设备指纹。
- 用户私人文本。

## 12. 视觉要求

整体风格：

- 简洁。
- 安静。
- 现代。
- 轻量。
- 适合长期使用。

要求：

- 当前题目是视觉中心。
- 不堆叠多层卡片。
- 不使用大面积渐变。
- 不使用游戏化高饱和配色。
- 不使用夸张动画。
- 桌面端保留足够留白。
- 移动端首屏能看到题目和输入框。
- 主题颜色统一由设计 Token 管理。

## 13. 引流设计

引流入口保持克制：

- 顶部显示“云北”入口。
- 页面底部展示相关文章。
- 页脚说明“由云北制作”。
- 复制的成绩文本中包含产品名称和域名。
- GitHub README 中链接云北个人主页。

禁止：

- 进入页面即弹出关注提示。
- 强制关注后使用。
- 练习过程中插入推广内容。
- 大面积展示个人介绍。
- 阻断练习流程的广告。

## 14. 数据分析

正式发布时只接入一种基础网站分析方案。

只统计：

- 页面访问量。
- 来源网站。
- 设备类型。
- 基础页面性能。

不发送：

- 练习答案。
- 错题内容。
- 具体按键。
- Zustand 本地状态。
- 用户身份信息。

## 15. MVP 验收标准

第一版必须满足：

1. 用户打开首页后可以直接开始练习。
2. 支持四种双拼方案。
3. 支持键位、单字和词组三种模式。
4. 输入正确和错误均有明确反馈。
5. 错误答案能够显示编码拆解。
6. 键位图能够随方案变化。
7. 设置和统计在刷新后保留。
8. 桌面端和移动端均可正常使用。
9. 不依赖后端、数据库和登录。
10. 运行过程中不请求远程业务 API。
11. 所有通用交互组件优先使用 shadcn/ui。
12. TypeScript、Lint、单元测试、浏览器流程测试和生产构建全部通过。
13. 主练习功能不需要跳转到其他页面。
14. 页面具备基础搜索和分享信息。
